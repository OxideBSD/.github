OxideBSD is a 4.4BSD-Lite inspired operating system with a kernel is written in Rust and a userland and libc that aspire to eventually also be written in Rust too. While it is not directly descended from any BSD operating system, it aspires to have a unique identity as a close UNIX cousin written from scratch. OxideBSD aims to eventually be a usable desktop operating system like a Linux distro or a BSD descendant.
